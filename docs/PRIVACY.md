# Privacy

Atmo Derma is designed to minimize sensitive data collection.

- Precise location should be used only for a requested environment lookup and should not become an implicit location history.
- Skin photos are optional. The intended workflow validates, analyzes, extracts structured indicators, and deletes the original unless retention is explicitly selected.
- Raw images and credentials must never be written to logs.
- Demo sensor readings are synthetic and visibly labeled `SIMULATED`.
- Future account controls must include data export, photo deletion, skin-history deletion, and account deletion.
